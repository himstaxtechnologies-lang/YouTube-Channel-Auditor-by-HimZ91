Enter any public channel and get a scored audit of upload consistency, engagement, reach, video optimization and channel profile, with a fix list ordered by impact.

First time here? Get your free API key (about 2 minutes)
  1. Go to console.cloud.google.com and sign in with any Google account.
  2. Click the project menu at the top, choose New Project, name it anything, and click Create.
  3. Open APIs & Services, then Library. Search for YouTube Data API v3 and click Enable.
  4. Open APIs & Services, then Credentials. Click Create credentials, choose API key, and copy the key.
  5. Paste the key in the box below. It is saved in your browser only.

The key is free and needs no credit card. You get 10,000 units a day and each audit uses about 4. Every person uses their own key, so never share yours.

Your key is stored in this browser only and is sent only to YouTube.
